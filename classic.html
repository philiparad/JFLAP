COMPATIBILITY MODE

Every original workspace.
The original algorithms.

This mode executes the unmodified JFLAP 7.1 JAR using the CheerpJ JavaScript/WebAssembly client library. It retains JFLAP’s guided exercises, conversion tools, pumping games and original Swing interface. It is separate from the independent JavaScript workbench.

First launch downloads the browser runtime and can take a minute. A desktop-sized browser works best. Files stay in the browser’s virtual filesystem until you download them.
